# 姨姨的語音

遊戲裡的語音（sounds/tts/*.mp3）是用 F5-TTS 複製姨姨的聲音做的。

- 參考錄音：姨姨 2026-10-10 的錄音（261010_105014.m4a），剪成 ref2.wav，
  文字「小朋友你好！我們今天來玩喔。先吹長長的氣氣，嘴巴圓圓的。」。
  錄音不放在這個公開的 repo，要自己放到這個資料夾。
- 語速：每秒 3.5 字，轉 mp3 時再加快 15%。
- `jobs.py`：列出要念的字詞；台灣念法和大陸不同的字用同音字合成（垃圾→樂色）。
- `f5gen.py`：產生 wav（Intel Arc xpu，每句約 20 秒）。
- `fixloop.py`：產生 → 轉 mp3 → 語音辨識檢查，沒過的重做。
- `hetcheck.py`：用語音辨識檢查最後一個字有沒有念出來。

新增字詞後：先跑 `node tools/gen_tts.js`（會用 Google 語音補缺的），
再用這裡的腳本把新的字詞換成姨姨的聲音。
- 「X的Y」一律合成成「X的，Y。」（的後面停一下），不然最後一個字常被吃掉或切掉。
- `fixloop2.py`：比 fixloop.py 嚴格，另外檢查聲調、結尾有沒有突然切斷、最後一個字前面有沒有停頓；
  每輪留分數最好的那一版。
- `tonecheck.py`：全部語音逐字比對聲調；`tailcheck.py`：把最後一個字單獨拿去辨識。
  語音辨識會用前後文「猜」字，所以通過不代表一定對，要搭配結尾音量檢查。
